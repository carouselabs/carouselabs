# CarouseLabs Comment — browser extension

Side-panel extension for AI-assisted LinkedIn commenting. Separate project
from `browser-extension-ideas/` (which is a plain-JS, no-build extension) —
this one is a Vite + CRXJS + React + TypeScript + Tailwind + shadcn/ui build,
since the side panel needs real UI state (routing between screens, forms,
live data) rather than a couple of static popup pages.

## Develop

```
npm install
npm run dev
```

Then in `chrome://extensions`:

1. Enable **Developer mode**.
2. **Load unpacked** → select this folder's `dist/` directory (Vite/CRXJS
   writes the built, loadable extension there — `npm run dev` keeps it live
   with HMR).
3. Click the toolbar icon — the side panel opens directly (no popup step).

## Build

```
npm run build
```

Outputs the loadable extension to `dist/`.

## Structure

- `manifest.config.ts` — MV3 manifest (via `@crxjs/vite-plugin`'s
  `defineManifest`), minimum permissions (`sidePanel`, `storage`,
  `clipboardWrite`), host permissions scoped to LinkedIn + carouselabs.com.
- `src/background.ts` — service worker. Currently just registers
  `chrome.sidePanel.setPanelBehavior({ openPanelOnActionClick: true })` so
  the toolbar action opens the panel with no popup intermediary. Real logic
  (auth, comment generation, page messaging) comes later.
- `src/sidepanel/` — the side panel's React app: `Header` (logo, pin, close),
  `IconBar` (Home / Profiles / History / Settings / Account), and one
  placeholder screen component per icon, switched via `activeScreen` state
  in `App.tsx` (no router needed for 5 flat screens).
- `src/components/ui/` — shadcn/ui components (`Button` scaffolded as the
  first one; add more with `npx shadcn add <component>` as real screens need
  them).
- `public/icons/` — toolbar icons, generated by `scripts/generate_icons.py`
  (`npm run icons` — requires Python + Pillow). Same placeholder approach as
  `browser-extension-ideas/icons/` (solid CarouseLabs purple `#7C3AED`
  square) but with a chat-bubble glyph instead of a lightbulb, so the two
  extensions are visually distinguishable in the toolbar.
